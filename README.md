# Itzfizz Animation

Scroll-driven hero animation featuring a top-view BMW M4 driving along a road, revealing a blue trail, headline, and animated statistics.

## Tech Stack
- React
- Vite
- GSAP & ScrollTrigger
- Tailwind CSS

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
